# JSON data types
1) Object -> {"key":"value"} -> named fields
2) Array -> 
  2.1) Array of strings ["Buy milk", "Call mom"]
  2.2) Array of ints [1, 2, 3]
  2.3) Array of bools [true, false]
  2.4) Array of nulls [null, null]
  2.5) Array of objects [{"id": 1}, {"id": 2}]
  2.6) Array of arrays [[1, 2], [3, 4]]
  2.7) Array of mixed data ["text", 5, true, null, {"a": 1}, [1, 2]]
  2.8) Empty array []
